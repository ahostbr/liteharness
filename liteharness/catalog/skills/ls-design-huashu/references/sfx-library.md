### Terminal Interaction Demo

```
type (0.5s) -> enter (0.5s) -> command-execute (0.5s) -> output-appear (0.6s)
```

Loop element: `cursor-blink` as ambient sound during idle state.

```

```

## Usage Guidelines

### Volume Recommendations (from the dual-track audio system in apple-gallery-showcase.md)

- **SFX main track**: `1.0` (no attenuation)
- **BGM background track**: `0.4 ~ 0.5` (SFX clearly cuts through)
- **Multiple SFX layered**: use `amix=inputs=N:duration=longest:normalize=0` to preserve dynamic range

### ffmpeg Mix Templates

```bash
# Align a single SFX to a time point:
ffmpeg -i video.mp4 -itsoffset 2.5 -i sfx/ui/click.mp3 \
  -filter_complex "[0:a][1:a]amix=inputs=2:duration=longest:normalize=0[a]" \
  -map 0:v -map "[a]" output.mp4

# Multiple SFX + BGM:
ffmpeg -i video.mp4 \
  -itsoffset 1.0 -i sfx/transition/whoosh-fast.mp3 \
  -itsoffset 1.6 -i sfx/impact/logo-reveal-v2.mp3 \
  -i bgm.mp3 \
  -filter_complex "[3:a]volume=0.4[bgm];[0:a][1:a][2:a][bgm]amix=inputs=4:normalize=0[a]" \
  -map 0:v -map "[a]" output.mp4
```

### Selection Decision Tree

1. **There is a tactile action** (typing/clicking/swiping) -> `keyboard/` or `ui/`
2. **Element enters or exits** -> `transition/`
3. **Container-level operation** (card/modal) -> `container/`
4. **State feedback** (success/failure/notification) -> `feedback/`
5. **Progress/time passing** -> `progress/`
6. **Brand impact/important moment** -> `impact/`
7. **AI magic/transformation** -> `magic/`
8. **Command line/code demo** -> `terminal/`

### Avoid Sound Stacking

- Maximum `2 SFX` concurrent at the same time point
- When BGM is below 0.3, 3 SFX can play simultaneously
- During brand impact moments, clear all other SFX (leave 0.2s silence before the impact hit)

## Prompt Writing Principles (for reuse)

Reference style: `apple keynote, tight, minimal, no reverb unless ambient, crisp, elegant`

**Three elements of a good prompt**:

1. **Physical sound description**: what object, what action ("mechanical keyboard single key press")
2. **Texture/style qualifier**: apple-style / ios-style / cinematic / retro
3. **Exclusion of negative examples**: no reverb / clean studio / minimal

Bad: "click sound"
Good: "crisp ui button click, clean modern interface sound, apple-style, high pitched"

Bad: "magic"
Good: "bright twinkling stars sound, high pitched glittery chime, fairy dust"
